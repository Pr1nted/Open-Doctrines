OpenDoctrines 0.0.0

Free, and the same game everywhere. If you would rather not download anything, it plays in a browser tab — no account, no install, the same worlds and the same saves.

Windows

Windows 10 or later, 64-bit. Unsigned, so SmartScreen asks once — More info → Run anyway.

macOS 11 or later. Unsigned, so the first launch is right-click → Open, not a double-click.

Android

Experimental. Android 7+, arm64. Verified on an emulator and never on a real phone. A controller plays it far better than fingers do.

Download .apk

TempleOS

The whole game in HolyC — map, rules and AI, nothing sent anywhere. Needs a virtual machine (QEMU, Bochs, VirtualBox): the screen mode it uses is one real graphics cards do not offer.

Download .zip

FreeBSD and OpenBSD are built and tested for every release, inside real BSDs, but they are not published as downloads yet — bsd-game.yml runs on request and leaves CI artifacts, which expire and need a GitHub account to fetch. Until they are attached to a release, build from source: the README covers it, and nothing in the build is Linux-specific.

Installers (.exe, .dmg) are on the releases page. The downloads above are zips: unpack and run, nothing is written outside the folder.
