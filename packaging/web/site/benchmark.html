How long does a turn take?

Six open-source strategy games, measured the same way, on one machine, on the same map, for the same number of turns. Not a review and not a score — a stopwatch. Open Doctrines is one of the six and wrote the harness, which is a conflict of interest worth stating; the method and the raw runs are published so the number can be checked rather than believed.

What is being measured

Turns per minute is the whole field: every game resolves a turn, so every game can be timed doing it. Frames per second and network bytes per minute only exist where a game has a renderer the harness can watch and a protocol it can read, which is why some rows are blank — a blank is a measurement that was not possible, not a zero.

Open Doctrines source · the harness is a separate C program and its runs are kept with their machine description, so a result carries the hardware it was taken on.
