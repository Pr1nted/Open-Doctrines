# CLA signatures

Everyone below has accepted the
[Contributor License Agreement](CLA.md).

Add yourself in the same pull request as your first change, at the end of
the table. Git records who added the line and when, and that commit is the
signature — there is nothing else to send and no form to fill in.

One row, in this shape:

```
| Your Name or handle | @github-handle | CLA 1.0 |
```

Use whatever name you want to be known by. It does not have to be a legal
name, and the project does not collect one. If you are accepting on behalf
of an employer, put the employer in the name column too — `Jane Roe
(Acme Ltd)` — because clause 7(c) of the CLA is about them, not only you.
